# Session Handoff: 2026-11-13 (first releases, v0.1.0 and v0.1.1)

## Summary

Cut the first release. v0.1.0 is published on GitHub with installers for all
three OSes. The first release run failed on Windows because of a test-only
bug. It was fixed on `main`, and the tag was moved to the fix and pushed again.
v0.1.0's only macOS dmg was arm64 and would not run on the user's Intel Mac, so
v0.1.1 added an x64 dmg, ad-hoc mac signing and an app icon.

## Completed

- PR #18: 0.1.0 entry in `CHANGELOG.md` (`package.json` was already 0.1.0).
- First Release run failed in `npm test` on `windows-latest`: 7 backup tests
  hit `EBUSY` because they deleted the temp folder while SQLite handles were
  still open. Linux and macOS passed; nothing was published.
- PR #19: backup tests track and close every handle before cleanup.
  Production code already closed its handles.
- Moved `v0.1.0` to the fix commit (`16c8fab`) and pushed it again. Second run
  passed on all three OSes and published the release:
  <https://github.com/ricschuster/finance-tracker/releases/tag/v0.1.0>
  - `finance-tracker-0.1.0-linux-x86_64.AppImage` (119 MB)
  - `finance-tracker-0.1.0-win-x64.exe` (102 MB)
  - `finance-tracker-0.1.0-mac-arm64.dmg` (115 MB)
- Design note 09: where installers land, the retag procedure, and the fact
  that the release run is the only Windows/macOS test run.

- PR #21 (v0.1.1): `macos-15-intel` in the Release matrix (x64 dmg), ad-hoc
  mac signing (`identity: '-'`, `hardenedRuntime: false`; v0.1.0's app had no
  signature at all), `workflow_dispatch` (builds without publishing), app icon
  (`build/icon.svg`, `scripts/render-icon.mjs`), README macOS 15 first-launch
  steps, ADR 0004 amended. `.github/actionlint.yaml` declares the
  `macos-15-intel` label for the pinned actionlint 1.7.7.
- A manual Release run on `main` built all four installers. Both dmgs were
  checked: app binary and `better_sqlite3.node` match the dmg's architecture,
  `_CodeSignature` present, `icon.icns` present. Then tagged `v0.1.1`:
  <https://github.com/ricschuster/finance-tracker/releases/tag/v0.1.1>
  (AppImage, win-x64 exe, mac-arm64 dmg, mac-x64 dmg).

## Current state

- The repository is private, so the release page and downloads need a signed-in
  account with access.
- Installers are unsigned (ADR 0004): Windows SmartScreen and macOS Gatekeeper
  warn on first launch (on macOS 15: Privacy & Security, Open Anyway).
- No installer has been launched by hand yet. The user is about to try the
  v0.1.1 x64 dmg on an Intel Mac running macOS 15.7.
